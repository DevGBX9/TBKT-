# The Block Keeps Ticking Plus

**إصدار ماينكرافت:** Java 26.3 — **المحمّل:** Fabric فقط — **Java:** 25

**The Block Keeps Ticking Plus** (يُختصر إلى **TBKT+**) هو نسخة مطوّرة من مود
[The Block Keeps Ticking](https://github.com/MagicJinn/The-Block-Keeps-Ticking) الأصلي.
يحافظ على جميع ميزات المود الأصلي، ويضيف:

* محاكي مزرعة بامبو كامل يعمل بالأحداث (Event-Driven) ويحترم قواعد اللعبة الأصلية.
* نظام تصحيح (Debug) يستطيع محاكاة **72,000 تكة** (ساعة واحدة) وحتى
  **1,728,000 تكة** (24 ساعة) في الجزء المحدد.
* تقارير عربية قابلة للقراءة في `config/tbkt-debug-reports/`.
* ملف إعداد تصحيح نصي لا يعمل تلقائياً أبداً.

> **ملاحظة توافق:** معرّف المود، ومعرّف إعدادات اللعبة، وملحقات الـ Chunk المحفوظة
> في العوالم القديمة تبقى كما هي (`the-block-keeps-ticking` /
> `the_block_keeps_ticking`)، لذلك يمكن استبدال الإصدار الأصلي بهذا الإصدار دون
> فقدان إعدادات العالم.

## التثبيت

1. ثبّت **Fabric Loader** المناسب لماينكرافت 26.3.
2. ضع `fabric-api-0.160.5+26.3.jar` في مجلد `mods`.
3. ضع `the-block-keeps-ticking-plus-26.3.jar` في مجلد `mods`.
4. شغّل اللعبة أو الخادم مرة واحدة. سيُنشأ ملف الإعدادات تلقائياً:
   * `config/the-block-keeps-ticking.json`
   * `config/the-block-keeps-ticking-debug.txt` (ملف تصحيح اختياري، لا يعمل تلقائياً)

على الخادم، لا يحتاج اللاعبون إلى تثبيت المود. يُثبَّت على الخادم فقط.

## الميزات

### 1) الميزات الأصلية المحفوظة

* محاكاة الكتل والكيانات في الأجزاء غير المحمّلة (Unloaded Chunks).
* محاكاة الكيانات الكتلية: الأفران، المشافي (Campfires)، ومنصات التخمير.
* المحاصيل والسيقان: القمح، الجزر، البطاطس، الشمندر، زهور الشعلة، اليقطين، والبطيخ.
* نبتة النيثر (Nether Wart) وحبوب الكاكاو.
* نمو الشتلات (Saplings) وذبول الأوراق (Leaves).
* الكيلب، البامبو، قصب السكر، والصبار.
* Ghast المجفف وبيض Sniffer (ترطيب وفقس).
* نمو Amethyst Budding.
* تقاطر الماء والحمم على المراجل (Cauldrons)، وتحول الطين إلى طين صلب فوق
  Dripstone، وترطيب Farmland.
* شجيرات التوت الحلو (Sweet Berry Bushes).
* نمو الكيانات العمرية (Ageable Mobs) ووضع بيض الدجاج في الأجزاء غير المحمّلة.
* أوضاع الوقت: وقت العالم (World Time) أو الوقت الحقيقي (Real Time).
* المحاكاة بعد النوم (Simulate After Sleeping).
* ضريبة الكسل (Lazy Tax) بنسبة مئوية.
* تمكين/تعطيل كل نوع من الكائنات المحاكاة على حدة.
* أوامر المالك/المشرف (Permission Level 4).

### 2) محاكي مزرعة البامبو (Plus)

المحاكي لا يعيد كتابة قواعد اللعبة، بل يستدعي دوال الفانيلا نفسها:

* `BlockState.randomTick` لنمو البامبو.
* `BlockState.tick` للمراقبين (Observers) والمكابس (Pistons).
* `BlockBehaviour.triggerEvent` لأحداث البلوك (فك وتركيب المكبس).
* `PistonMovingBlockEntity.tick` لحركة رأس المكبس.
* `HopperBlockEntity.pushItemsTick` لحركة القمع.
* `HopperBlockEntity.addItem` لنقل العناصر بين الحاويات.

يستخدم المحاكي طابور أحداث (Priority Queue) مع سياق محاكاة خاص بالخيط
(`SimulationContext`)، ويجمع:

* التكات المجدولة داخل الجزء المستهدف عبر `LevelTicksMixin`.
* أحداث البلوك عبر `ServerLevelBlockEventMixin`.
* العناصر المتولدة عبر `ServerLevelAddEntityMixin`.
* إزالة البامبو عبر `LevelSetBlockMixin`.
* نقل القمع عبر `HopperBlockEntityMixin`.

### 3) محاكاة دقيقة وقابلة للتقسيم

* التوزيع العشوائي للتكات (Random Ticks) يعتمد على تجزئة حتمية (Deterministic Hash)
  لكل قسم (Section) ولكل تكة.
* لذلك فإن محاكاة 72,000 تكة دفعة واحدة تعطي النتيجة نفسها التي تعطيها 72 محاكاة
  متتالية بمقدار 1,000 تكة، من نفس الجلسة.
* الجلسة (Session) محفوظة لكل جزء، لذلك تستمر المحاكاة المجزأة من حيث توقفت.
* أمر `run-file` يعيد ضبط الجلسة قبل التشغيل؛ أما `simulate chunk` فلا يعيد ضبطها.

### 4) تكامل مع المحاكاة التلقائية

* البامبو مستبعد من المحاكي العام القديم لمنع النمو المزدوج.
* عند عودة اللاعب إلى جزء غير محمّل، تُشغَّل جلسة المزرعة مرة واحدة لكل مهمة
  (Job)، ثم يكمل المحاكي العام بقية الكتل.
* المحاكاة التلقائية تحتفظ بضريبة الكسل وحدّ الحد الأدنى لوقت السكن
  (Min Inhabited Time)، بينما أمر التصحيح يتجاوزهما لضمان أن `simulate_hours=1`
  تعني **72,000 تكة بالضبط**.

## الإعدادات

يمكن تعديل الإعدادات عبر:

* `config/the-block-keeps-ticking.json`
* الأمر `/tbkt config`
* Mod Menu + YACL (على العميل)

### الخيارات العامة

| الخيار | النطاق | الافتراضي | الوصف |
| --- | --- | --- | --- |
| `timeMode` | `WORLD_TIME` / `REAL_TIME` | `WORLD_TIME` | مصدر الوقت المستخدم في حساب المحاكاة |
| `lazyTaxPercent` | 0–99 | 0 | نسبة تقليل التكات المحاكاة |
| `simulateChunksWhenSleeping` | true/false | true | محاكاة الأجزاء المحمّلة عند تخطي الوقت بالنوم |
| `minInhabitedTicks` | 0–24000 | 6000 | أقل وقت سكن للجزء قبل محاكيته (6000 = 5 دقائق) |
| `debugLogging` | true/false | false | تسجيل تفاصيل إضافية في سجل الخادم |

### الكائنات القابلة للتمكين/التعطيل

كل كائن محاكاة له اسم مستقل، ويمكن تمكينه أو تعطيله:

```text
/tbkt config set tickingObject false "Bamboo Stalk"
/tbkt config set tickingObject true "Chicken Egg Laying"
```

استخدم `/tbkt config` لعرض الأسماء المتاحة فعلياً في نسختك.

## الأوامر

جميع الأوامر تتطلب **مستوى صلاحية 4** (Owner/OP). كل أمر متاح أيضاً تحت الاسم
الكامل `/theblockkeepsticking`.

### أوامر الإعداد

```text
/tbkt config
/tbkt config reload
/tbkt config set <option> <value>
/tbkt config set tickingObject <true|false> <name>
```

### أوامر المحاكاة

```text
/tbkt simulate chunk <ticks> [<chunkX> <chunkZ>]
/tbkt simulate block <ticks> [<x> <y> <z>]
```

* `simulate chunk` يحاكي كل الكائنات المدعومة في الجزء المحدد.
* إذا حُذفت الإحداثيات، يُستخدم جزء اللاعب المنفّذ.
* يجب أن يكون الجزء **محمّلاً**، وإلا يظهر خطأ واضح.
* `simulate block` يحاكي كتلة أو كياناً كتلياً واحداً مدعوماً.

### أوامر التصحيح

```text
/tbkt debug status
/tbkt debug run-file
/tbkt debug simulate chunk <ticks> <chunkX> <chunkZ>
/tbkt debug report
```

هذه الأوامر متاحة أيضاً كاختصارات قديمة:

```text
/tbkt status
/tbkt run-file
/tbkt report
```

* `status`: يعرض إصدار ماينكرافت والمود، مسار ملف التصحيح، مسار التقارير، وآخر
  تشغيل.
* `run-file`: يقرأ `config/the-block-keeps-ticking-debug.txt` ويشغّله. لا يعمل
  تلقائياً أبداً.
* `simulate chunk`: محاكاة دقيقة للجزء المحدد بالعدد المطلوب من التكات.
* `report`: يعيد كتابة تقرير جديد لآخر نتيجة دون إعادة المحاكاة.

الحد الأقصى لعدد التكات في أوامر التصحيح هو **1,728,000** تكة (24 ساعة). يتم رفض
القيم السالبة أو الأكبر من ذلك برسالة خطأ.

## ملف التصحيح

المسار:

```text
config/the-block-keeps-ticking-debug.txt
```

القالب الافتراضي:

```properties
enabled=false
dimension=minecraft:overworld
chunk_x=0
chunk_z=0
simulate_hours=1.0
debug_logging=false
generate_report=true
```

* `enabled=false` يعني أن `/tbkt run-file` سيتخطى التشغيل.
* الملف **لا يعمل تلقائياً** عند بدء الخادم أو تحميل الجزء.
* الملف يُقرأ فقط عند تنفيذ `/tbkt run-file`.
* كل الحقول السبعة مطلوبة، والتكرار أو المفاتيح المجهولة أو القيم خارج النطاق
  تُرفض برسالة واضحة.

للتفاصيل الكاملة، أمثلة، وسيناريوهات الاختبار، راجع
[DEBUG-GUIDE.md](DEBUG-GUIDE.md).


```bash
./gradlew :fabric:build
```

```text
fabric/build/libs/the-block-keeps-ticking-plus-26.3.jar
```

يُبنى أيضاً JAR المصادر باسم منفصل، ولا يُضمَّن في حزمة الإصدار.

## القيود المعروفة

* محاكي التصحيح يتطلب أن يكون الجزء المستهدف **محمّلاً** مسبقاً؛ لا يقوم بتحميله.
* الحد الأقصى للتصحيح هو 24 ساعة (1,728,000 تكة) لكل استدعاء.
* المحاكاة التلقائية عند العودة تقصّ الطلبات الأطول من 24 ساعة إلى الحد الأقصى
  مع تسجيل تحذير، بدلاً من إفشال المهمة.
* لا يتم تسجيل سطر لكل تكة؛ التقارير إجمالية فقط.
* بعض ميزات الفانيلا (مثل الفقس والـ Ghast المجفف) تفقد قدراً ضئيلاً من الدقة
  بسبب طريقة معالجة الزمن، كما في المود الأصلي.
* المحاكاة تعمل على خيط الخادم الرئيسي؛ المحاكاة الطويلة جداً قد تستهلك وقتاً
  ملحوظاً على خوادم ضعيفة.
* إزالة المود قد تترك رسائل سجل غير ضارة عن أنواع ملحقات غير معروفة
  (قيد Fabric وليس خطأً في المود).
